# Brain Tumor MRI Classifier Dataset

The model is trained on the following dataset:

- **Source**: Kaggle
- **Link**: [Brain Tumor MRI Images - 44 Classes](https://www.kaggle.com/datasets/fernando2rad/brain-tumor-mri-images-44c)
- **Description**: Contains 44 classes of brain tumors, covering Glioma, Meningioma, Pituitary, and healthy scans, captured in various MRI sequences (T1, T1C+, T2).
